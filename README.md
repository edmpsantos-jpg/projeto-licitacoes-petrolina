Arquitetura do Projeto
Este projeto implementa um pipeline de dados utilizando a nuvem Microsoft Azure.
Storage: Azure Data Lake Storage Gen2 (Região Chile).
Processamento: Azure Databricks com Apache Spark (PySpark).
Visualização: Power BI Desktop conectado ao Data Lake.
Conteúdo
Tratamento_Dados_Petrolina.py: Script de ETL para limpeza e seleção de colunas.
Dashboard_Petrolina_Final.pbix: Relatório interativo com ranking de fornecedores e secretarias.
Objetivo
Fornecer transparência e ferramentas de análise para a fiscalização de contratos públicos de Petrolina de Goiás.
